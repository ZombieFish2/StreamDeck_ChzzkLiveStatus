# 치지직 방송 상태 Stream Deck 플러그인 (CHZZK Live Status)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Stream Deck](https://img.shields.io/badge/Stream%20Deck-v6.0+-blue)](https://www.elgato.com/stream-deck)
[![Node.js](https://img.shields.io/badge/Node.js-v20+-green)](https://nodejs.org/)

네이버 **치지직(CHZZK)** 스트리머의 실시간 방송 상태를 Elgato Stream Deck 버튼에서 한눈에 확인하고, 원클릭으로 해당 방송에 즉시 접속할 수 있는 스트림덱 플러그인입니다.

순수 벡터 SVG 렌더러와 인메모리 캐싱을 통해 화면 깜빡임이 전혀 없으며, 단일 스트리머 모드와 여러 스트리머를 묶어 관리할 수 있는 통합 모드를 지원합니다.

## 🌟 주요 기능

### 1. 단일 스트리머 버튼 (`치지직 스트리머 (단일)`)
- **프로필 사진 100% 핏**: 버튼 전체를 스트리머 프로필 이미지로 가득 채워 높은 시인성 제공.
- **직관적인 상태 인디케이터**:
  - **방송 중 (LIVE)**: 선명한 원본 컬러 프로필 + 좌측 상단 **빨간 원(`●`)** 라이브 인디케이터.
  - **오프라인 (OFF)**: 채도 25% 유지(인물 식별 가능) + 좌측 상단 **화이트 도넛 링(`○`)** 오프라인 인디케이터.
- **채널 바로가기**: 버튼을 누르면 해당 스트리머의 치지직 방송 페이지(`https://chzzk.naver.com/live/{channelId}`)가 기본 브라우저에서 즉시 열립니다.
- **편리한 등록**: 설정 창에서 스트리머 닉네임을 검색하여 선택하거나, 32자리 고유 채널 ID를 직접 입력할 수 있습니다.

### 2. 통합 스트리머 버튼 (`치지직 스트리머 (통합)`)
- **1개 버튼으로 여러 스트리머 관리**: 좋아하는 스트리머 여러 명을 등록하고 우선순위를 정할 수 있습니다.
- **스마트 우선순위 표시**:
  - 평소에는 **우선순위가 가장 높은 방송 중(온라인) 스트리머**의 컬러 프로필이 자동으로 표시됩니다.
  - 추가로 방송 중인 스트리머가 더 있을 경우 우측 상단에 **`+N`** 뱃지(치지직 민트 컬러)가 표시됩니다.
  - 모두 오프라인일 때는 1순위 스트리머의 오프라인 프로필이 표시됩니다.
- **직관적인 조작 제스처**:
  - **단일 클릭 (Click)**: 현재 방송 중인 다음 스트리머로 순환 표시.
  - **더블 클릭 (Double Click)**: 즉시 1순위 기본 화면으로 초기화.
  - **길게 누르기 (Long Press, 0.5초 이상)**: 현재 화면에 표시된 스트리머의 치지직 채널 바로 열기.

### 3. 공통 API 프록시 / 캐시 서버 전역 공유 (`Global Settings`)
- [Chzzk-API-Cache](https://github.com/ZombieFish2/Chzzk-API-Cache) 같은 캐시/프록시 서버와의 연동을 완벽 지원합니다.
- **전역 설정 자동 공유**: 아무 버튼에서나 프록시 주소를 한 번만 입력하면 모든 버튼에 자동으로 공유되어, 새 버튼을 추가할 때마다 주소를 반복해서 입력할 필요가 없습니다.
- 외부 도메인, HTTPS, 로컬 주소(`localhost:8000`), 커스텀 포트가 완벽하게 지원됩니다.

### 4. 강력한 안정성 & 깜빡임 완전 방지
- **초경량 썸네일 최적화**: 2MB가 넘는 고용량 원본 프로필 사진도 스트림덱 해상도에 맞춘 경량 포맷(`f120_120`, 약 28KB)으로 다운로드하여 속도와 메모리를 98.6% 절감합니다.
- **깜빡임 없는 렌더링**: 상태 변경이 없을 때는 불필요한 이미지 재설정을 스킵하여 완벽한 무깜빡임 디스플레이를 유지합니다.
- **오류 내구성**: 네트워크 단절이나 일시적 API 오류 발생 시에도 마지막 상태를 안전하게 보존합니다.

## 📦 설치 및 사용 방법

### 방법 1: 설치 패키지 사용 (가장 간편한 방법)
1. GitHub 저장소의 **[Releases](../../releases)** 페이지에서 최신 `com.chzzk.livestatus.streamDeckPlugin` 파일을 다운로드합니다.
2. 다운로드한 `.streamDeckPlugin` 파일을 더블 클릭하면 Elgato Stream Deck 프로그램에 자동으로 설치됩니다.
3. Stream Deck 앱의 액션 목록에서 **치지직 (CHZZK)** 카테고리를 찾아 원하는 버튼으로 끌어다 놓습니다.

### 방법 2: 소스코드 직접 빌드 및 개발
Node.js(v18 이상)가 설치된 환경에서 직접 빌드하고 로컬에 배포할 수 있습니다:

```bash
# 1. 저장소 복제
git clone https://github.com/ZombieFish2/StreamDeck_ChzzkLiveStatus.git
cd StreamDeck_ChzzkLiveStatus

# 2. 의존성 설치
npm install

# 3. 빌드, 패키징 및 로컬 스트림덱에 자동 배포
npm run pack
```

> `npm run pack` 스크립트를 실행하면 최신 코드가 빌드된 후 사용자 PC의 Stream Deck 플러그인 디렉터리(`%APPDATA%/Elgato/StreamDeck/Plugins/`)로 자동 복사·동기화됩니다.

## ⚙️ 설정 가이드

### 1. 스트리머 등록
- **검색 이용**: 설정 창 상단의 검색창에 스트리머 이름을 입력하고 결과에서 클릭하면 채널 ID와 프로필이 자동 설정됩니다.
- **채널 고유 ID 직접 입력**: 치지직 채널 주소의 끝자리 32자리 고유 해시값을 직접 입력할 수 있습니다.
  - 예: `https://chzzk.naver.com/live/516937b5f85cbf2249ce31b0ad046b0f` 주소인 경우 `516937b5f85cbf2249ce31b0ad046b0f` 입력.

### 2. 갱신 주기
- 기본값은 **60초**이며, 10초 ~ 600초 사이에서 자유롭게 조절할 수 있습니다.

### 3. 공통 API 프록시 / 캐시 서버 (선택사항)
- 치지직 공식 API 서버에 직접 요청하지 않고 자체 구축한 캐시 서버를 경유하고 싶을 때 사용합니다.
- 주소 예시:
  - `http://localhost:8000`
  - `https://proxy.yourdomain.com`
  - `http://192.168.1.100:8000`
- 비워두면 치지직 공식 서버로 직접 안전하게 통신합니다.
